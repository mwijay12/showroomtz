# **App Name**: VoltaRentals

## Core Features:

- EV Fleet Catalog: Browse available electric vehicles with high-resolution images, specifications, and suitability for various event types (weddings, corporate, etc.).
- Event Booking Form: Submit detailed booking requests, including event type, desired dates and times, pick-up/drop-off locations, and special requirements.
- AI Event-Fit Advisor: An AI tool that analyzes booking details to recommend the best EV models or suggest optimal timings based on vehicle availability and event context.
- Admin Booking Dashboard: Administrators can review, approve, deny, and manage all incoming booking requests, update vehicle status, and adjust pricing.
- User Account & Booking History: Authenticated users can view their upcoming and past bookings, check status updates, and manage their profile details.
- Automated Notifications: Send automated email or in-app notifications for booking confirmations, changes, and reminders to both users and admins.

## Style Guidelines:

- Primary brand color: A deep, elegant sapphire blue (#1F59CC), symbolizing luxury, reliability, and sophistication for event and corporate bookings. HSL: (220, 70%, 40%)
- Background color: A subtly textured dark charcoal (#1F232E) derived from the primary hue, providing a modern, premium feel that enhances the brightness of content. HSL: (220, 20%, 15%)
- Accent color: A vibrant, clear sky-cyan (#4CD5ED) used for calls-to-action, highlights, and status indicators, suggesting innovation and energy. HSL: (190, 80%, 65%)
- Unified font: 'Inter' (sans-serif) for both headlines and body text. Its clean, modern, and highly legible design conveys professionalism and contemporary elegance.
- Employ a suite of sleek, minimalistic line icons that communicate functionality clearly without distraction, aligning with the modern EV aesthetic.
- Adopt a spacious, grid-based layout with generous whitespace to ensure content breathability and a premium, uncluttered user experience.
- Incorporate subtle, fluid animations for navigation transitions and interactive elements to provide a responsive and polished feel, enhancing the user journey.
